# Keramat Tomato

Tomato-style VPN management project.

## Current baseline
- VLESS account management
- VLESS multi-transport configuration
- Backup and Xray validation helpers
- Debian 13 compatibility is a project target

## Roadmap
- SSH / SSH WS
- VMess
- Trojan
- OpenVPN / ZiVPN
- Tomato-compatible multi-port routing

Only source code belongs in this repository. Never commit customer databases,
real UUIDs, passwords, certificates, private keys or production configuration.
